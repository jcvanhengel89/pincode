# Pincode PWA

Bestanden voor de installeerbare iPhone-versie.

## Publiceren
Upload de volledige inhoud van deze map naar een HTTPS-webhost.
GitHub Pages is hiervoor een eenvoudige gratis optie.

Belangrijk:
- `index.html`, `manifest.webmanifest` en `service-worker.js` moeten in dezelfde hoofdmap staan.
- De map `icons` moet mee.
- Open de gepubliceerde HTTPS-pagina één keer in Safari op de iPhone.
- Kies Deel > Zet op beginscherm.
- Daarna start Pincode als losse app en werkt de kern ook offline.
